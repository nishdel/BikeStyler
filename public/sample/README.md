# Prepared examples

`champagne.bike.json` is the repository owner's contributed bicycle, isolated on white with existing manual masks. It includes several saved variations and generated reference cutouts. Publication was expressly authorized. Metadata, original surroundings, identifying names and recorded measurements were removed. See [asset permissions](../../docs/ASSETS.md); no general downstream photo licence is asserted.

`sample.bike.json` is the prepared Raleigh sample available from the welcome screen. Its photograph is [Raleigh Road Bike](https://commons.wikimedia.org/wiki/File:Raleigh_Road_Bike.jpg), friedjof / Melaenea, 2017, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Manual masking, component annotation, white-background isolation and metadata removal are modifications. Derivative photographic material retains CC BY-SA 4.0. No endorsement is implied.

Import either file with **Import portable project**. Both include the pixels needed for their designs and do not rely on private source files. These examples demonstrate visual editing, not mechanical compatibility.
