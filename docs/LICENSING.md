# Licensing status

No general licence for BikeStyler's application code has been established. Publication does not silently grant an MIT, Apache or other open-source licence. `package.json` therefore says `UNLICENSED`; the repository is public source pending an owner decision.

**Recommendation for a later decision:** consider MIT for the owner's original application code if broad reuse with attribution is desired. This is a recommendation, not an adopted licence. Review ownership and contribution terms before adding a licence file. Any future code licence should expressly exclude separately licensed or permission-limited images, product marks and other assets.

Existing CC0 declarations for original code-defined component artwork are retained. They do not automatically license the rest of the application. Third-party photographs retain their CC BY-SA 4.0 attribution and derivative obligations. The contributed bicycle example and generated assets have permission for this repository's publication, but no blanket downstream image licence is asserted. See [ASSETS.md](ASSETS.md) for each group.

Third-party npm dependencies retain their own licences in their installed packages. React/React DOM, Vite, TypeScript, Vitest and Playwright are separate works; the lockfile records the selected packages. No bundled proprietary font is included; the interface uses system fonts. Product names and trademarks identify catalogue references and do not imply endorsement.
